## 源码确认的依赖与状态

```text
MarginLinkPlugin ── 每个 MarkdownView 一个 MarginOverlay ── NativeScrollLayer
  │                    ├─ EditorBridge / ReadingAnchors → Anchor(start, fragments)
  │                    ├─ StableLayout → layout-engine → Placement
  │                    ├─ TextObstacles → connectorBatch → connector-renderer
  │                    │                                    ↓
  │                    │                   有向共享线段、SVG、配对续接
  │                    └─ DragController / CardDragController → 校验后提交
  └─ SelectionAction / LayoutStore → Editor transaction / 插件 data.json
```

- `MarginOverlay.render` 确认源文与路径，缓存 measured anchors、可见区、续接序号和稳定位置；按视图协调 DOM 测量、路径批次和卡片事件。scroll、resize、mutation、字体和编辑器通过 rAF 合并。文件/模式更换清卡；leaf 移除或插件卸载经 destroy 取消 observer、帧、计时器、手势并拆除 DOM。
- 编辑器通过 CM visibleRanges 和 DOM Range 测量，阅读通过 postprocessor section 的真实链接和源偏移映射；两者的绘制 key 都是当前文档 start 字符串。同一偏移在编辑后可能属于另一条链接。基线 highlight 在每次 pointermove 遍历全部卡和路径并解析成员 JSON；没有独立 pin，键盘焦点与指针共同覆盖一个字段。
- `connectorBatch` 接收端点 fragments、卡片位置、边界、文字与卡片障碍、线宽，返回逻辑关系及有向共享段。覆盖区外跳过搜索，但卡片仍为障碍。几何签名/指纹与最近 100 条成功路径复用；精确平移后对当前全部障碍与边界重验。候选按评分下界剪枝；曲线保守细分判碰撞，采样仅参与美观评分。同侧共享切分保留方向，滚动静默 160 ms 再探索共享。阻塞/裁切可生成编号对，隐藏模式维持隐藏。障碍和候选增多放大逐段检测，共线片段匹配与邻卡摆放有成对比较，算法没有固定帧时保证。
- `LayoutStore` schema 2 白名单验证，旧平铺偏好加载、未知版本不解释为位置。仅保留合法相对坐标、时间、源路径和唯一弱身份；原文字串/前后 48 字符/重复数作散列，重复候选不匹配。CRLF/LF 仅归一身份，并可唯一迁移旧别名；完整 metadata 文本才触发清理。rename/delete 处理源及子路径，重链别名支持原生撤销。500 全局、100 每笔记、90 天。freeze 初次填空不更新时间或挤掉旧项；同源分屏完全手动切换优先最近操作视图。插件 queueSave 合并 250 ms，flush 串行快照，卸载发起最后一个待写快照，宿主退出时异步完成仍受宿主生命周期限制。

## 测试证据与设计边界

`connector-{batch-overlay,route-cache,sharing-cache,clearance,scroll-batch}` 覆盖有向接缝、描边、平移验证、离屏回入与必要重搜；`continuation-overlay` 覆盖双端编号；`layout-{store,line-endings,navigation}`、`manual-persistence`、`relink-action`、`card-drag-controller` 和 `plugin-lifecycle` 在本轮基线全部通过。真实宿主中的像素、焦点顺序、异步预览与跨 leaf 需要桌面补证。

缺口为临时与固定状态仲裁、单 occurrence 局部更新、跨视图过期摘要与文件失效、折叠后的路径成员和布局稳定性。将摘要时序与分组规则独立，保留已验证路线与存储算法。范围限于当前源笔记，仅读取用户请求的小文件纯文本，无网络、全库扫描、持久正文或全局图谱。
