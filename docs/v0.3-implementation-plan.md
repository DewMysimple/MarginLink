## 兼容性与交互取舍

- 单键仅在聚焦卡片时生效。普通点击、Enter/Space、Ctrl/Cmd 点击、选区事务和原生正文链接沿用已有处理。临时状态可以退出，固定目标随源文或模式切换失效。
- preview 使用本地已安装 Obsidian 类型中公开的 Vault.cachedRead、TFile.stat 和已有链接解析。摘要最多 700 个 Unicode 码点；超过 256 KiB 仅读元信息。预览靠边距定位，小空间逐级缩短，有空间时提供打开按钮。
- 分组方式属于跨会话设置，添加到 schema 2 偏好白名单，旧数据缺项或非法值迁移为 none，旧版本也可忽略该新选项并继续读取 layouts。折叠、固定、预览、缓存均在视图内存。第一版选文件夹和文件类型；标签涉及多标签归属与重复展示，留待真实使用需求。
- 各阶段运行完整单测并单独提交。桌面场景使用隔离 Vault/profile，证据与未覆盖条件写入 VALIDATION。高亮和分组复用路线安全机制，不调整碰撞容差、手动偏移、依赖或 minAppVersion。

## 实施记录

| 阶段 | 实际结果 |
| --- | --- |
| A | 记录 3c7f420 基线、499 项测试与架构审计。 |
| B | 局部更新上一个与当前 occurrence 的有向成员段。阅读锚点用原链接元素，编辑锚点按文本片段在滚动层画底纹。基线实测阅读 sizer 会单独移除装饰层，现由 observer 请求重挂载。500 项全测通过。 |
| C | TargetPreview 拥有窗口事件、两个延时和面板，PreviewSummaries 拥有 24 条、60 秒有效期的内存摘要。请求以 session 对象身份、视图、文件及修改版本复核。键盘主动打开才将焦点移入面板，Esc 还给卡片。510 项全测通过。 |
| D | GroupControls 用官方 ItemView.addAction（1.1.0）和原生 Menu 将组开关放入笔记标题栏，所有卡片折叠后仍可访问。卡片正文显示组名，图标卡保留紧凑外观；命令支持隐藏标题栏的布局。groupOccurrences 按完整源文、每种目标字符串解析一次；规则或 Vault 路径解析变化使结果失效。519 项全测通过。 |
| E | 将卡片事件绑定移出几何循环。预览位置避开正文、卡片、选区手柄与编号，源文/几何更换及销毁时清理。下一帧探针发现已移除的编辑高亮仍可收到样式记录，加入脱离视图判定及独立回归后消除多余批次。54 文件、521 项全测通过。 |
| F | 对预览面板进行桌面目视复核，优先使用卡片旁的完整边距，让打开按钮独立于滚动摘要。最终 54 文件、522 项测试，Windows 1.10.6 与 1.15.1 的隔离安装包均通过，五文件 ZIP 逐字节复核通过。[验证记录](../VALIDATION.md) |

公开 Vault.cachedRead 始于 0.9.7，getFileByPath 始于 1.5.7。签名和版本来自安装的官方 obsidian.d.ts。回滚时可替换旧版五个发布文件并保留 data.json。0.2.27 可继续读 schema 2 位置，写入时会忽略新增分组选项。
