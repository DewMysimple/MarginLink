# v0.3 空间导航实施方案

| 阶段 | 输入、所有权与输出 | 验收 |
| --- | --- | --- |
| A 审计 | 对比 0.2.27 源码、基线命令与历史桌面记录 | 见 [审计](v0.3-audit.md) |
| B 路径高亮 | 每个 overlay 保存临时、固定和选区状态；用 occurrence start 和现成 relation.segments 更新上一个及当前卡片、锚点、编号、共享段 | 同目标独立，P 或菜单固定，Escape 取消，几何/保存计数不变 |
| C 目标预览 | 每个视图一个控制器，接收卡片、解析目标及打开动作；延迟悬停与键盘 V 请求。纯文本 DOM，读取前限文件大小，缓存带路径、版本、容量和时限 | 附件、空/大文件、异常、迟到请求、切页和卸载，鼠标与键盘交接 |
| D 分组 | 只分类当前文档的 occurrence；按完整父目录或扩展类型建立稳定分组。边距中的组控件折叠/展开，已保存位置优先；折叠过滤显示，位置仍按完整输入计算 | 默认无，重复引用、同名文件、丢失目标、两种规则和四种布局 |
| E 整理 | 检查独立控制器释放、数据失效和现有协调边界 | 单元与渲染集成回归 |
| F 交付 | 对照相同测试夹具、宿主和视口，记录本轮桌面与性能样本；核对版本与安装目录 | 完整 test/lint/build/package、文档、工程记忆及 Git |

## 兼容性与交互取舍

- 单键仅在聚焦卡片时生效。普通点击、Enter/Space、Ctrl/Cmd 点击、选区事务和原生正文链接沿用已有处理。临时状态可以退出，固定目标随源文或模式切换失效。
- preview 使用本地已安装 Obsidian 类型中公开的 Vault.cachedRead、TFile.stat 和已有链接解析。摘要最多 700 个 Unicode 码点；超过 256 KiB 仅读元信息。预览靠边距定位，小空间逐级缩短，有空间时提供打开按钮。
- 分组方式属于跨会话设置，添加到 schema 2 偏好白名单，旧数据缺项或非法值迁移为 none，旧版本也可忽略该新选项并继续读取 layouts。折叠、固定、预览、缓存均在视图内存。第一版选文件夹和文件类型；标签涉及多标签归属与重复展示，留待真实使用需求。
- 各阶段运行完整单测并单独提交。桌面场景使用隔离 Vault/profile，证据与未覆盖条件写入 VALIDATION。高亮和分组复用路线安全机制，不调整碰撞容差、手动偏移、依赖或 minAppVersion。
