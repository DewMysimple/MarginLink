# 当前约束

## 用户要求与技术约束

- 原生非嵌入 Wikilink 是唯一关系源；新增关联必须为 `[[目标路径|原文字]]`。禁止关系数据库、sidecar、关联 frontmatter、隐藏 ID/注释、替身 Markdown、外部关系服务。
- 仅四项 UI 偏好可经官方 loadData/saveData 持久化；每条链接的位置、路径和 ID 不落盘。布局确定性重建，不承诺跨会话保留拖放位置。
- 正文、原生点击/悬停、正常选区拖动和编辑焦点保持可用；每视图独立，窄窗允许隐藏而不挤压正文。源码写入只用选区事务，确保取消、过期快照和撤销重做安全。
- HTML/思维导图不由本插件渲染、转换或外部启动；能解析目标与拥有查看器是不同能力。未知类型需已打开的兼容 FileView 通过公开接口确认。
- 用户明确指定 standard 工程记忆。维护遵循 `wiki_memory/AGENTS.md`，不把当前状态写成聊天复刻，也不把工程文档作为运行时关系索引。

## 兼容性与操作边界

桌面插件，manifest 最低 1.10.6；已有本机 1.10.6 主体构建、1.15.0 最终构建验收记录。不能把早期 1.10.6 结果当作最终代码完整重测，也不承诺移动端、其他系统和所有第三方组合。

测试只针对本工程 `test-vault/` 与 `test-profile/`，不改用户正式笔记库、不把插件安装进 Obsidian 程序目录。测试准备脚本会重置夹具；不复制用户账户数据或整个正式 profile。

用户持续授权本项目的 Git 提交与推送。每次完整对话有项目修改时，完成必要验证及记忆同步，审查并提交本轮改动，推送已核实 upstream，核对远程提交并报告；无需重复确认。无改动不造空提交；失败如实报告、保留提交，不强推。完整执行规则在根 [AGENTS.md](../../AGENTS.md)。当前目标仓库为 `https://github.com/DewMysimple/MarginLink.git`；这项授权不外延至其他项目、发布社区插件、发消息或更改仓库权限。
