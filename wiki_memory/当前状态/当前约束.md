# 当前约束

## 用户要求与技术约束

- 固定高亮与目标摘要由当前 MarkdownView 管理。2026-11-19 起，点击文件卡前的折叠状态、引用代表和卡位可在原标签最近八次文件卡导航中恢复。跨会话仅将分组方式写入 schema 2 偏好白名单，缺失或非法时关闭。预览不执行目标内容，并限制读取尺寸、摘要长度、缓存数量及有效期。

- 原生非嵌入 Wikilink 是唯一关系源；新增关系只经安全选区 Editor 事务输出 `[[目标路径|原文字]]`。禁止关系库、笔记 sidecar、关联 frontmatter、隐藏 ID/标记、替身 Markdown 或外部关系服务。
- 用户于 2026-11-23 要求新增当前笔记全文检索建链，并在写入前审核大小写及范围。Agent 采用默认单处关联、可选全文预览、忽略大小写与整词匹配默认值。确认后使用同一目标和各处原文字作为别名，在一次 Editor 事务中写入。已有双链、代码和其他受保护语法保持原样，审核结果只留在弹窗内存中。
- v0.2 明确取代旧版“仅四项 UI 偏好、不能保存单卡位置”的限制：允许原有插件 data.json 中的全局白名单外观与受限相对 UI 布局。不能生成新关系、保存正文副本、向笔记写身份或在设置以外新增持久化文件。
- 位置必须匹配当前真实唯一锚点；歧义/过期/损坏按当前模式给初始位置。只有drop/稳定时机合并保存，不在pointermove或分隔线调整写盘。schema2沿用；placementMode独立。v0.2.2首次/缺失/无效回退always/free/square，已有合法偏好（包括旧auto/hover/horizontal）逐项保留，恢复默认外观保留当前布局模式、方向、栅格与位置。
- 空白带限当前 MarkdownView，不能压正文、侧栏、标题/状态栏或其他 leaf。原生文本选择、建链手柄、点击和撤销保持可用，卸载取消捕获并清理全部附加 UI。
- HTML/思维导图不由本插件运行或转换；解析和查看器能力分开。0.2.7 将已成功注册或明确被其他处理器占用的 HTML/HTM/XMind 纳入可打开范围。其他未知类型仍需已打开的兼容 FileView 通过公开接口确认。
- 工程记忆只是协作文档，不参与插件运行。按项目协议维护 standard 五页/决策/日志，不复刻聊天。

2026-11-17后续要求已按顺序实现：重链仍一笔原生正文事务，原生snapshot仅恢复UI视口；面板同步聚焦输入，无延迟强行回拉滚动/焦点，不新增运行时关系数据。

2026-11-17用户要求全手动及返回位置稳定：新增manual独立初排，无平衡/挤开；进入前冻结已测位置。free/snap只自动初排一次，稳定显示批量初始化UI位置，受原容量/身份限制且不在move或每帧刷新；auto不写。设置禁用不适用控制，重置/恢复外观不偷偷切模式。

用户更新：自由/吸附放置仅影响当前出现位置，2026-11-19 起拖动落点也须保持卡片间距；自动基准独立于手动记录，只有显式全局整理才重排范围。当前搜索没有安全路线时用配对编号续接，不能静默消失，也不能把有限搜索失败称为几何上绝对不可能。共享成员与全文顺序编号只在绘制内存中，不能持久化关系。2026-11-16 用户进一步要求实际笔记缺线整改、直线/直角减少转折：首选1.5px/紧凑0.5px的额外留白均保护完整文字框及最大高亮描边，方向搜索计转弯成本，共享不得增加成员转折。未移动用户卡片或修改源文来取得连线。

2026-11-16 的 0.2.16–20 计划授权：单击选区图标打开同一面板，库外文件操作须由用户明确确认。复制校验、确认原生编辑事务、复核源和目标后才删来源。来源绝对路径只在操作 UI 使用。新建与导入共用三个目录，附件不补 .md。重新链接只修改经过校验的这一次 Wikilink，保留别名并明确处理子路径，阅读模式与其他分栏须校验。可证明对应的 UI 布局身份迁移及 Undo/Redo 临时别名不构成关系库。依据为项目 prompt 中的 0.2.16–20 执行计划及实际 selection-action/local-file-import/relink 实现。

2026-11-23 用户要求库外导入遇到同名文件时可显式覆盖或安全重命名。安全重命名保留扩展名并从 ` (1)` 起找空闲编号，写入仍使用排他创建。覆盖经二次确认，同一路径原有双链继续指向该路径。Agent 选择遮蔽正在关联或在编辑视图中打开的目标笔记的覆盖选项，并在写链失败时保护并发变更与旧文件备份。「使用已有文件」保留库外原件。

## 兼容性与操作边界

当前开发交付版为 0.3.4，minAppVersion 声明为 1.10.6。各宿主及版本的实测范围见 VALIDATION。左Ribbon打开右侧完整设置ItemView，原生设置页保留并共用表单；快捷Modal保留。共享h2精确为MarginLink，原生select局部固有宽度/换行保护；已移动标签复用，“当前笔记”按最近操作Markdown视图判定。不使用私有设置导航，不承诺全部第三方组合。

0.3.1 的自由/吸附布局区分初排和用户拖放。视图按 10px 同列间距修正相撞的初排卡位，既有坐标保留。旧记录缺乏来源时，采用 Agent 选择的内边缘启发式。2026-11-19 用户更新要求后，四种布局统一避开重叠。手动记录保留原始相对坐标，显示层在发生碰撞时选取空位。

已有卡片移除六点握柄，卡片自身单击打开、达到阈值后拖动和键盘调整；正文选区建链手柄继续保留。加载、空白或局部渲染不允许清理位置；清理使用文件明确的完整文档真实变更。源 rename/delete 定向处理，无关文件保留布局。具体决策见 ADR-003。

本轮用户要求：充足边距连续resize不能隐藏整层；真实不足只降级/隐藏受影响卡片及线，恢复不改记录。卡片hover最多一个文件名/类型提示；鼠标移动已有卡片全程无跟随文字，按下即收起hover。整卡抓点比例取实际外框CSS坐标，先命中再定位与约束，不用子元素offset。实现细节及实证局限见本轮日志/VALIDATION。

测试只对本工程 test-vault 与隔离 test-profile，准备脚本会重置夹具和旧偏好样本；禁止向真实 Vault 写测试文件或复制用户整个 profile。安装到 Vault 插件目录，不装进程序目录。

用户 2026-11-10 的持续 Git 授权仍有效。每次完整对话有项目修改则验证、同步持久事实、审查并提交本轮改动，再推送已核实的 upstream。目标仓库为 DewMysimple/MarginLink。执行边界和失败处理见根 AGENTS。

用户 2026-11-23 增加本地交付要求。每次有项目改动都运行 `npm run package` 并复核 `dist/margin-link/` 与当前 manifest 版本 ZIP。校验新包成功后清理 `dist/` 内其他版本的 MarginLink ZIP，最后报告远程提交与本地产物位置。构建物沿用 Git 忽略规则。
