# 当前约束

## 用户要求与技术约束

- 原生非嵌入 Wikilink 是唯一关系源；新增关系只经安全选区 Editor 事务输出 `[[目标路径|原文字]]`。禁止关系库、笔记 sidecar、关联 frontmatter、隐藏 ID/标记、替身 Markdown 或外部关系服务。
- v0.2 明确取代旧版“仅四项 UI 偏好、不能保存单卡位置”的限制：允许原有插件 data.json 中的全局白名单外观与受限相对 UI 布局。不能生成新关系、保存正文副本、向笔记写身份或在设置以外新增持久化文件。
- 位置必须匹配当前真实唯一锚点；歧义/过期/损坏回退自动。只有 drop/稳定时机合并保存，不在 pointermove 写盘。schema 2 安全迁移旧 enabled/lines/density/layout，placementMode 独立，旧用户默认 auto。
- 空白带限当前 MarkdownView，不能压正文、侧栏、标题/状态栏或其他 leaf。原生文本选择、建链手柄、点击和撤销保持可用，卸载取消捕获并清理全部附加 UI。
- HTML/思维导图不由本插件运行或转换；解析和查看器能力分开。未知类型仍需已打开的兼容 FileView 通过公开接口确认。
- 工程记忆只是协作文档，不参与插件运行。按项目协议维护 standard 五页/决策/日志，不复刻聊天。

## 兼容性与操作边界

版本统一 0.2.0，minAppVersion 1.10.6。已在 Windows 的 1.10.6/1.15.0 分别完整运行 44 桌面场景；不承诺移动端或所有第三方组合。快速完整设置共用公开 Modal 表单，原生设置页保留，不使用私有设置导航。

测试只对本工程 test-vault 与隔离 test-profile，准备脚本会重置夹具和旧偏好样本；禁止向真实 Vault 写测试文件或复制用户整个 profile。安装到 Vault 插件目录，不装进程序目录。

用户 2026-11-10 的持续 Git 授权仍有效：每次完整对话有项目修改则验证、同步持久事实、审查并提交本轮改动、推送已核实 upstream；无变化不造空提交。失败保留提交并报告、不强推。目标仓库 DewMysimple/MarginLink；授权不扩展到其他项目、社区发布或权限修改。执行规则见根 AGENTS。
