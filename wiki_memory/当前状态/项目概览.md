# 项目概览

## 项目目标与阶段

当前版本 0.2.8；新增内容坐标排布、每窗格滚动缓存及实际滚动客户区裁切，桌面复核受环境套接字权限阻塞。此前 0.2.3–0.2.7 实现四边连线、HTML 字标、精简选区手柄提示、三个新建目录及 Ctrl 新窗口，并通过公开扩展名注册使原生文件列表识别 HTML/HTM 与 XMind。2026-11-16 的自动化与桌面限界见 [验证记录](../../VALIDATION.md)。下段为此前 0.2.2 验证背景。

MarginLink是Obsidian原生非嵌入Wikilink的边缘可视化交互层，关闭插件后链接仍有效。v0.2.2迭代连续resize、文件名/类型单提示、无跟随文字和抓点保持；新默认always/free/square，旧合法偏好与手动布局保留。右侧完整设置、原生设置页和快捷控制共用偏好。最低版本声明1.10.6，本轮最终桌面实测1.15.1；未发布社区目录或远程Release。

位置是可清除的插件 UI 偏好，只有当前真实 Wikilink 锚点可生成卡片，删除 UI 数据不改变关系。[README](../../README.md) 为使用/安装依据，[更新记录](../../CHANGELOG.md) 与[验证报告](../../VALIDATION.md) 说明本轮范围。

## 核心入口

- `src/main.ts`：生命周期、命令、串行/合并保存和每视图 overlay；`src/types.ts`：外观白名单、类型与默认值。
- `src/core/layout-identity.ts`、`layout-store.ts`：弱匹配、schema 迁移、UI 位置限额与失效；`src/view/layout-engine.ts`：纯几何和碰撞。
- `src/view/card-drag-controller.ts` 是已有卡片移动；`src/editor/drag-controller.ts` 是选区建链，二者独立。
- `src/ui/settings-tab.ts`、`settings-view.ts`、`quick-controls.ts`：共享原生表单/预览、右侧 ItemView 与快捷 Modal。
- `tests/`、`scripts/desktop-test.mjs`/`desktop-v2.mjs`、`desktop-stability.mjs`为测试入口；`preferences-restart-check.mjs`核对配置正常重启。数据与来源策略见[ADR-003](../决策/ADR-003-完整源文清理与整卡交互.md)。
