# 项目概览

## 项目目标与阶段

MarginLink 是 Obsidian 原生非嵌入 Wikilink 的边缘可视化交互层，关闭插件后链接仍有效。v0.2.0 已实现可调连线、auto/free/snap 相对布局、横向/正方形/图标卡片、原生分组设置/预览/快捷控制。目标最低 Obsidian 1.10.6，桌面 MVP 已完成隔离验收，进入用户环境使用与复核阶段；未发布社区目录或远程 Release。

位置是可清除的插件 UI 偏好，只有当前真实 Wikilink 锚点可生成卡片，删除 UI 数据不改变关系。[README](../../README.md) 为使用/安装依据，[更新记录](../../CHANGELOG.md) 与[验证报告](../../VALIDATION.md) 说明本轮范围。

## 核心入口

- `src/main.ts`：生命周期、命令、串行/合并保存和每视图 overlay；`src/types.ts`：外观白名单、类型与默认值。
- `src/core/layout-identity.ts`、`layout-store.ts`：弱匹配、schema 迁移、UI 位置限额与失效；`src/view/layout-engine.ts`：纯几何和碰撞。
- `src/view/card-drag-controller.ts` 是已有卡片移动；`src/editor/drag-controller.ts` 是选区建链，二者独立。
- `src/ui/settings-tab.ts`、`quick-controls.ts`：同一状态的原生表单/预览与 Modal。
- `tests/`、`scripts/desktop-test.mjs`/`desktop-v2.mjs` 为测试入口。布局策略见 [ADR-002](../决策/ADR-002-v0.2可清除的相对布局偏好.md)。
