# 已知问题

## 未解决问题与影响

1. 历史2026-11-10：1.15.0更新包+1.10.6安装程序在CDP关闭独立设置窗口时产生无堆栈illegal access，当时两组主题/一组编辑器设置共18条宿主诊断；卸载插件后仍复现。具体宿主原因未知，不归因插件、不声称修复。历史1.10.6同44场景零告警，本轮1.15.1结果另见VALIDATION。
2. UI 弱身份对局部上下文/同原文数量变化敏感，重复同上下文不保存位置。v0.2.1 已改为源路径定向 rename/delete，不再因无关附件清空其他布局。真实原生双链被自动改写、上下文变化时，对应位置仍可能安全回退。
3. MarginLink 0.2.7 已注册的 HTML/HTM/XMind 可由本插件附件页打开；其他未知或第三方类型仍可能需要先打开兼容 FileView。公开 API 不能枚举未打开的处理器。
4. 保留单一普通行内选区、表格拒绝/转义 Wikilink 跳过、阅读 DOM 歧义省略、窄横向空间时卡片降级/隐藏等边界。第三方主题/DOM/悬停处理器、popout、其他系统/RTL/移动端、全部媒体格式仍未验收。
5. 2026-11-16 在 1.10.6 发现 source→preview 会将 CRLF 文件保存为 LF，卸载插件后同样发生。单纯拖卡片保持 CRLF 原字节；跨模式位置恢复正常。无插件、各阶段哈希证据见 artifacts/crlf-host-control.json；不以插件写回文件干预宿主行为。
6. 本轮1.15.1未复现用户截图的下拉框箭头only；已增加局部固有宽度/换行保护，并验证260/360/600与明暗/键盘/重开。不能据此声称查明原截图宿主/主题根因。卡片单提示仅在本轮默认主题实证，其他悬停扩展组合仍未知。

7. 0.2.8–0.2.10 在当前 Linux 环境仅完成232项单测及构建；Obsidian/Chromium 在插件加载前因套接字权限被阻塞，真实滚动帧、文字避线、卡片原尺寸及第三方主题效果待桌面复核。

## 复现与临时处理

- 告警：隔离 1.15.0 执行 test:desktop，查看两个带版本 JSON 和原始诊断；`node scripts/host-window-control.mjs` 对照编辑器窗口，先卸载再恢复插件。旧主题对照保留在 desktop-control-plugin-unloaded.json。只分类精确特征与阶段，其他异常仍失败；后续复核新安装程序和正常操作，不掩盖错误。
- 位置失效：保持各引用具有不同周围文字；真实上下文变化后的回退仍需重新拖放。切页的旧编辑器清理竞态、首次整卡拖动的延迟活动事件、CRLF 跨模式身份差异已修复，证据与覆盖见 VALIDATION。大小/限额/过期见 README；记录不是关系备份，不把偏移量或隐藏 ID 当作修复方案。
- 特殊类型：先用已有处理器打开同类文件并保留标签，再试卡片；无支持时保留链接/提示，不转换或外部执行。
- 用户组合：先在默认主题/无 DOM 改写的独立库比较，收集最小复现；完整人工步骤在根 README。120 链接和短时反馈检查不是大型性能/泄漏证明。
- v0.2.2已实证修复RO/几何暂隐、阈值处晚一绘制帧降级、中心抓点跳变和卡片多来源诊断提示。0.2.8起仅完全离屏卡片移除，部分露出自然裁切；横向空白不足仍是自适应规则，不能当闪烁；逐帧分类及系统截图在VALIDATION和stability-final.json。idle800ms计数0证明本次稳定窗口停止重排，不等于任意长期/插件组合的泄漏证明。
