# 已知问题

## 未解决问题与影响

1. 本机 1.15.0 更新包 + 1.10.6 安装程序在 CDP 关闭独立设置窗口时产生无堆栈 illegal access。本轮两组主题/一组编辑器设置共 18 条宿主诊断；卸载插件后对应复现仍存在。具体宿主原因未知，不归因插件、不声称修复。1.10.6 同一 44 场景零告警。
2. UI 弱身份对局部上下文/同原文数量变化敏感，重复同上下文不保存位置；任何 Vault rename/delete 都清空全部坐标。这是防错配的保守取舍，链接完全保留，但无关卡片位置也可能重置。
3. HTML/未知类型需要已打开的兼容 FileView；装了处理器但未打开同类视图仍可能提示未确认。公开 API 不能枚举未打开的处理器。
4. 保留单一普通行内选区、表格拒绝/转义 Wikilink 跳过、阅读 DOM 歧义省略、窄窗/密集卡片隐藏等首版边界。第三方主题/DOM/悬停处理器、popout、其他系统/RTL/移动端、全部媒体格式仍未验收。

## 复现与临时处理

- 告警：隔离 1.15.0 执行 test:desktop，查看两个带版本 JSON 和原始诊断；`node scripts/host-window-control.mjs` 对照编辑器窗口，先卸载再恢复插件。旧主题对照保留在 desktop-control-plugin-unloaded.json。只分类精确特征与阶段，其他异常仍失败；后续复核新安装程序和正常操作，不掩盖错误。
- 位置失效：保持各引用具有不同周围文字；清理后自动布局，必要时重新拖放。大小/限额/过期默认值见 README；记录不是关系备份。不要把偏移量或隐藏 ID 当作修复方案。
- 特殊类型：先用已有处理器打开同类文件并保留标签，再试卡片；无支持时保留链接/提示，不转换或外部执行。
- 用户组合：先在默认主题/无 DOM 改写的独立库比较，收集最小复现；完整人工步骤在根 README。120 链接和短时反馈检查不是大型性能/泄漏证明。
