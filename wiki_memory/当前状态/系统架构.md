# 系统架构

## 模块职责与边界

`main.ts` 注册公开 Obsidian 生命周期、CM6 扩展、Markdown 后处理器和事件；每个 MarkdownView 对应独立 `MarginOverlay`，卸载时清理 overlay、observer、阅读子组件和编辑器桥。

| 模块 | 职责 |
| --- | --- |
| `src/core/` | 基于 mdast 源位置筛选双链，排除保护区域；原生解析精确目标；安全别名/路径格式化；检查文件类型打开能力 |
| `src/editor/` | CM6 文档版本、可见范围和实际坐标；选区快照验证；手柄拖放/取消；单次公开 Editor 事务 |
| `src/reading/` | 官方后处理 section 源范围与 DOM 锚点映射；重复链接按目标组及源码顺序消歧 |
| `src/view/` | 可见锚点、确定性防重叠布局、SVG 曲线、主题卡片及双向悬停高亮 |
| `src/ui/` | 原生 FuzzySuggestModal 文件选择器与显示偏好设置 |

用户指定“原生双链唯一关联数据源”；Agent 在授权内采用 mdast 排除保护区域、每视图覆盖层和保守文件能力检查，已实现。依据与代价见[存储决策](../决策/ADR-001-原生双链作为唯一关联数据源.md)。工程 `wiki_memory/` 不参与插件运行。

## 数据流与依赖

编辑器当前文档 → `parseDocument` → 每次双链 occurrence → `getFirstLinkpathDest`/子路径 → 可见锚点 → 布局 → 卡片与曲线。阅读模式以官方 section 信息映射实际链接；数量无法消歧时省略目标组。

创建流程：单一合法选区 → 快照 → 拖放或命令 → 原生已有文件选择器 → 重查源文件、版本、文本、选区、活动视图及目标文件 → `exactTarget` → `formatWikilink` → 一次 `Editor.transaction()`。取消和失效都不写入；撤销重做由宿主管理。

唯一持久化是 `saveData(readPreferences(...))`，仅 `enabled/lines/density/layout`；关系、坐标、路径均不保存。卡片使用安全文本节点。官方 Obsidian/CM6 接口由宿主提供；`mdast-util-from-markdown` 及其依赖打包进产物，无后端服务。

## 运行与部署

源码克隆后 `npm ci`，开发监听 `npm run dev`；构建 `npm run build`（含 TypeScript 检查），单测 `npm test`，lint `npm run lint`。`npm run package` 生成 `dist/margin-link/`，打包依赖许可证；ZIP 生成命令见根 README。

发布内容复制到 `<Vault>/.obsidian/plugins/margin-link/` 后启用，不复制到程序安装目录。Git 不跟踪依赖、bundle、dist 或隔离 profile，保留 README 引用的截图及诊断结果。

桌面复测先构建、运行 `node scripts/setup-test-vault.mjs`，再用 `scripts/launch-test.ps1` 启动隔离实例并运行 `npm run test:desktop`。默认程序在 `D:/SoftWare/Obsidian`，测试库/profile 位于本工程，CDP 端口 9223；结束关闭隔离实例。准备脚本会重写夹具，禁止指向正式库。
