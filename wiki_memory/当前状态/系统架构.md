# 系统架构

## 模块职责与边界

主入口 `main.ts` 注册公开 Obsidian/CM6/后处理生命周期，每个 MarkdownView 独立 overlay。关闭时清理图层、观察器、捕获和 managed Modal；原 Markdown 与原生交互保留。

| 模块 | 职责 |
| --- | --- |
| core 原有解析/格式化/能力 | mdast 保护区域与精确原生目标；HTML 等未知类型只确认公开 FileView 能力 |
| core/layout-identity | 文档变化时组合散列原文、两侧 48 字符和同原文数量；整篇唯一才给 UI 弱身份 |
| core/layout-store | schema 2 迁移、严格位置白名单、500 总/100 每笔记/90 天限额、去重和清理 |
| editor | CM6 当前文本/解析/身份缓存、可见 DOM 坐标；原选区手柄/命令与单次事务创建双链 |
| reading | 官方 section 源范围与真实 DOM 链接按规范目标分组匹配；重复及普通链接消歧 |
| view/layout-engine | 形状尺寸、空白带、比例/行高坐标、手动优先碰撞、栅格吸附、裁剪纯函数 |
| view/card-drag-controller | 已有卡片握柄拖动，捕获/阈值/取消与 drop；不编辑笔记 |
| view/margin-overlay | 每视图测量、rAF 合并、可见锚点、复用 DOM、连线/高亮；侧栏动画几何暂隐 |
| ui | 原生分组设置及实时预览；快捷/完整 Modal 共用表单与主插件偏好订阅 |

原生双链唯一关系源继续有效，v0.2 可清除布局取舍及选择者见 [ADR-002](../决策/ADR-002-v0.2可清除的相对布局偏好.md)。

## 数据流与依赖

当前源文档 → 保护区域解析 → 原生 occurrence + 当前唯一弱身份 → 原生解析器/实际 DOM 锚点 → 每视图局部几何 → 读取可匹配 UI 位置 → 自动/自由/吸附排布 → SVG/卡片。记录自身不能创建 occurrence，离屏/无空间项隐藏。

新建：选区快照 → 原手柄或命令 → 原生 Fuzzy 选择器 → 重查文本/版本/选区/活动视图/实际文件 → 精确目标 → 一次 Editor.transaction。移动：卡片独立握柄 → 局部约束与实时连线 → drop 保存相对 UI 值。焦点移到其他控件、失焦、滚动或视图变化取消。

持久化唯一为插件 loadData/saveData：preferences 白名单 + layouts。主入口串行保存，布局 drop 后 250ms debounce，退出刷出待保存数据；无独立关系服务。任意 Vault rename/delete 保守清空全部坐标；普通当前文档编辑清理失配项。Obsidian/CM6 外置，mdast 依赖打包，无运行时网络。

## 运行与部署

`npm ci`；`npm test`；`npm run lint`；`npm run build`（tsc + esbuild CJS）；`npm run package` 生成带许可证的 dist/margin-link。ZIP 命令和升级说明在根 README。发布文件复制到 `<Vault>/.obsidian/plugins/margin-link/`，Git 不跟踪构建物或依赖。

测试入口：构建 → 关闭隔离实例后 `node scripts/setup-test-vault.mjs` → `scripts/launch-test.ps1` → `npm run test:desktop`。准备脚本重置测试库、工作区和 v0.1 偏好；只用于本工程。默认程序 D:/SoftWare/Obsidian，profile 为 test-profile，CDP 本机 9223，结束关闭实例。补充 host-window-control 和 restart-layout-check 脚本，流程见 README。
