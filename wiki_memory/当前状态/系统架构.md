# 系统架构

## 模块职责与边界

2026-11-19，开发分支增加每视图独立的同文件引用索引。分组依据为已解析文件路径，列表、代表锚点和组卡位只在内存中存在。绘制批次以 occurrence 偏移标识路线，以 cardKey 识别目标障碍。聚合卡位绕过持久化入口。详见[设计](../../docs/reference-aggregation-design.md)。

主入口 `main.ts` 注册公开 Obsidian/CM6/后处理生命周期，每个 MarkdownView 独立 overlay。关闭时清理图层、观察器、捕获和 managed Modal；原 Markdown 与原生交互保留。

| 模块 | 职责 |
| --- | --- |
| view/target-preview | 每窗格拥有悬停计时器、焦点交接、过期请求与有界摘要缓存。Markdown 以纯文本节点显示。 |
| view/card-groups、group-controls | 按源文 occurrence 和已解析目标分类，标题栏原生菜单控制折叠。完整稳定布局先计算，再筛选绘制成员。 |
| core 原有解析/格式化/能力 | mdast 保护区域与精确原生目标；HTML 等未知类型只确认公开 FileView 能力 |
| core/layout-identity | LF 统一上下文散列原文、两侧 48 字符和同原文数量；保留阅读原始偏移及旧 raw key 兼容；整篇唯一才给 UI 弱身份 |
| core/layout-store | schema 2 迁移、严格位置白名单、500 总/100 每笔记/90 天限额、去重和清理 |
| editor | CM6 当前文本/解析/身份缓存、可见 DOM 坐标；原选区手柄/命令与单次事务创建双链 |
| reading | 官方 section 源范围与真实 DOM 链接按规范目标分组匹配；重复及普通链接消歧 |
| view/layout-engine | 形状尺寸、空白带、比例/行高坐标、手动优先碰撞、栅格吸附、裁剪纯函数 |
| view/card-drag-controller | 已有整卡外框抓点比例；先指针命中空白带再推矩形及约束，move/up共用路径；阈值/取消/单次提交/本手势点击抑制；不编辑笔记 |
| view/margin-overlay、native-scroll-layer | 每窗格固定交互层与原生内容装饰层分离；卡片/线/编号共享滚动变换，已测区间不求路/改d/重定位编号。RO/Mutation/CM合帧，阅读同一sizer移除层后安全重挂载，卸载恢复拥有的样式 |
| core/local-file-import、ui/file-picker | 单一文件面板识别关键词/库内路径/库外绝对路径；文件系统事务独立封装只读预览、排他分块复制/摘要、源文提交回调、复核后删除；失败阶段保留可恢复副本 |
| editor/selection-action、core/relink | 选区创建和一次出现位置重链共享受校验的 Editor.transaction，读写/分栏校验、显式子路径策略；前后真实解析对齐可证明的 UI 身份，LayoutStore临时别名和编辑事件处理Undo/Redo |
| view/card-tooltip、card-renderer | 每document至多一个可取消延迟提示，只显示文件名/类型；aria-labelledby安全文本供无障碍，移除宿主aria-label与原生title两来源 |
| ui | 原生分组设置、实时预览与右侧完整 ItemView 共用表单/订阅；快捷 Modal 保留，最近 Markdown 决定当前笔记 |

原生双链唯一关系源继续有效，当前布局与交互选择见 [ADR-003](../决策/ADR-003-完整源文清理与整卡交互.md)。

## 数据流与依赖

当前源文档 → 保护区域解析 → 原生 occurrence + 当前唯一弱身份 → 原生解析器/实际 DOM 锚点 → 每视图局部几何 → 读取可匹配 UI 位置 → 自动/自由/吸附排布 → SVG/卡片。记录自身不能创建 occurrence，离屏/无空间项隐藏。

新建：选区快照 → 原手柄或命令 → 原生 Fuzzy 选择器 → 重查文本/版本/选区/活动视图/实际文件 → 精确目标 → 一次 Editor.transaction。移动：卡片本体整框抓点 → 约5px阈值 → 原始指针命中 → 抓点候选矩形/目标侧实际尺寸 → 边界/吸附/避让及实时连线 → up同路径单次保存。键盘保持中心语义。已有卡片拖动无跟随文字，dragHints仅控制边界；原生选区建链ghost独立保留。取消语义和延迟激活保护沿用。

持久化唯一为插件 loadData/saveData：preferences 白名单 + layouts。主入口串行保存，布局 drop 后 250ms debounce，退出刷出待保存数据；无独立关系服务。overlay 新源完整读取确认后显示，异步过期结果丢弃、有限退避；视图渲染不清理记录。metadataCache.changed 仅对文件明确的完整文档清理，旧编辑快照跳过；Vault rename/delete 定向源路径迁移/删除。Obsidian/CM6 外置，mdast 依赖打包，无运行时网络。

## 运行与部署

`npm ci`；`npm test`；`npm run lint`；`npm run build`（tsc + esbuild CJS）；`npm run package` 生成带许可证的 dist/margin-link。ZIP 命令和升级说明在根 README。发布文件复制到 `<Vault>/.obsidian/plugins/margin-link/`，Git 不跟踪构建物或依赖。

Windows 可双击根目录 `buildStart.cmd`：通过 `scripts/build-latest.ps1` 检查 main/已跟踪文件无修改，执行 `git pull --ff-only origin main`，确认 HEAD 等于 origin/main，再安装依赖、编译打包并按 manifest 版本生成 ZIP。随后实际解压刷新 dist/margin-link，对五个发布文件以 .NET SHA-256 校验，更新文件夹日期，显示目录、版本、完成时间和源码提交。依赖镜像放行仅限本次 npm ci，不更改全局配置。出错停止，窗口保留结果；`--no-pause` 用于终端自动运行。2026-11-16 首次入口完整运行与 9 项检查见[构建日志](../日志/工程维护/2026-11-16-Windows一键构建.md)；目录刷新及最终真实五步验证见[刷新日志](../日志/Bug处理/2026-11-16-构建目录刷新与校验.md)、[校验兼容性更正](../日志/Bug处理/2026-11-16-产物校验兼容性更正.md)。此工具不更改插件运行时或 Vault。

测试入口：构建 → 关闭隔离实例后 `node scripts/setup-test-vault.mjs` → `scripts/launch-test.ps1` → `npm run test:desktop`。准备脚本重置测试库、工作区和 v0.1 偏好；只用于本工程。默认程序 D:/SoftWare/Obsidian，profile 为 test-profile，CDP 本机 9223，结束关闭实例。补充 host-window-control 和 restart-layout-check 脚本，流程见 README。
