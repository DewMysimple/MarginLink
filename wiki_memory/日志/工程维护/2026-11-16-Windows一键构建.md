# Windows 一键构建

## 目标与结果

用户要求将根目录已有空文件 `buildStart.cmd` 实现为双击构建最新版本的入口。新增 PowerShell 工作流，更新中英文使用说明和架构运行入口；插件版本保持 0.2.2，运行时源码未修改。

入口自动定位项目，不依赖启动时工作目录；提前确认 Git、Node、npm，要求 main 分支且已跟踪文件无待提交修改。仅快进拉取 origin/main，HEAD 与远程跟踪分支一致才继续；不切分支、不自动处理本地修改或改写历史。使用 npm ci --allow-remote=all 兼容锁文件既有镜像地址，仅限本次命令且保留完整性校验。

依次安装依赖、执行 npm run package（含类型检查与构建），校验 package/manifest 版本一致，生成 dist/margin-link-<版本号>.zip。ZIP 先写临时文件，成功后替换同版本旧包；失败不继续后续步骤，窗口显示原因并提示已有包可能过期。默认暂停供双击查看，--no-pause 支持终端运行。PowerShell 文件使用 UTF-8 BOM，兼容 Windows PowerShell 5.1 中文；已加载函数避免拉取更新脚本自身影响当次执行。
