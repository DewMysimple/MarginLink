# 卡片菜单复制原文

用户要求从截图中的卡片右键菜单仅复制该次 Wikilink 的原文，例如 `imperative languages`。普通卡片菜单增加「复制原文」。Agent 为合并卡片在引用列表每一行提供同一操作，保留按出现位置选择的语义。使用所属窗口剪贴板，保留非空别名的原始字符，无别名或空别名使用目标路径和子路径。复制与解除链接共用此规则。

基线为 `main/1aa105e` 加本轮改动。Windows 下 `npm test` 通过 567 项，`npm run lint`、`npm run build` 通过。实际 Obsidian 隔离桌面结果见 [VALIDATION](../../../VALIDATION.md)。
