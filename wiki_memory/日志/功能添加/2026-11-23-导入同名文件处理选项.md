# 库外导入同名文件的处理选项

用户要求在关联文件弹窗增加覆盖替换及安全重命名。Agent 采用预览首个空闲编号、覆盖二次确认和已有文件复用。编号留在扩展名前，已被文件或文件夹占用的编号会跳过。若预览后的编号被占用，刷新下一个编号并等待确认。

覆盖先在目标所在卷校验新副本和旧内容备份，再替换原路径。关联失败时，目标仍与本次替换一致才恢复旧内容，否则保留备份及库外原件。普通导入、编号导入和覆盖在原生双链提交后才尝试删除库外原件。保护正在建立关联的笔记和仍在编辑视图中打开的目标笔记。
