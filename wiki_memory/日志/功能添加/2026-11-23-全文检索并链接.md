# 全文检索并链接

用户希望选中一次 `portable` 后可关联同篇笔记中的重复文字，并自行审核大小写。Agent 保留单处关联为默认方式，在关联文件面板增加全文检索。默认忽略大小写、只匹配整词，可逐项取消勾选。每处显示行号、上下文与原本拼写，原选区始终包含。

检索使用当次源编辑器快照，排除已有链接、代码、属性、表格及会破坏标签、脚注、块 ID 等语法的匹配。确认范围后，选择已有文件、新建或导入文件时，用同一目标和各处原文字生成原生 Wikilink。全部修改通过一次事务写入，一次原生撤销或重做覆盖整批。源笔记、选区或目标变化时复核并停止陈旧操作。

基线为 `main/160c0e4` 加本轮改动。Windows 下 `npm test` 通过 582 项，`npm run lint` 和 `npm run package` 通过。两版 Windows Obsidian 的隔离实测范围与打包校验见 [VALIDATION](../../../VALIDATION.md)。
