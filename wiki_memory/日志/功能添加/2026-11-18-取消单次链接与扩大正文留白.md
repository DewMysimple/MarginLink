# 取消单次链接与扩大正文留白

用户要求从卡片菜单取消文件链接，正文边缘留白上限提高到 300，只交付安装包和源码。起点 main/10a92fc。0.3.2 通过同一套已校验的编辑器事务保留别名或目标文字，保全相邻引用的布局，支持撤销和重做。阅读视图检测宿主沿用旧源文的段落后重新渲染。设置控件与偏好读取共用上限，预览处理空间不足，打开设置时避免重复保存。

Windows Obsidian 1.10.6、1.15.1 隔离实测覆盖重复引用、失效链接、CRLF、实际卡片和正文净距、插件重新加载及退出后的磁盘检查。535 项测试、lint、package 和 ZIP 载荷校验通过。复验入口与打包指纹见 VALIDATION。本轮未测试其他平台。
