# 分隔线拖动性能

从干净的 `main/aec1499` 开始。前一轮只读核查了截图、真实笔记、设置、事件链和历史窄栏回归。本轮使用隔离副本重放原生分隔线。UE6 笔记识别 91 条 Wikilink，使用合并同文件引用和悬停平滑曲线。旧包每轮约 7900 次路由搜索，三轮各 72 个长任务。

Agent 采用按当前正文几何失效测量、按所属分栏调度编辑器更新、悬停模式按当前互动关系求路，保留卡片同帧裁剪和当前障碍验证。原生分隔线长按期间推迟布局初始化，并在静止后完成必要更新。阅读宿主移除装饰层时，将原装饰节点立即重新连接到仍有效的同一正文容器。

Windows Obsidian 1.15.1 三轮相同右侧拖动，帧间隔 P95 中位数从 375.8 ms 降到 6.3 ms，最终每轮拖动及松手后均无长任务。复验涵盖 1.10.6、两侧分隔线、源码和阅读视图、固定连线、分栏和卸载。阅读的极窄阈值仍观察到偶发长任务，详情和复跑入口见 [VALIDATION](../../../VALIDATION.md)。

`npm test` 通过 596 项，`npm run lint` 和 `npm run package` 通过。最终 0.3.2 本地安装目录和 ZIP 五个发布文件一致。验证使用隔离库，正式笔记复核散列一致。
