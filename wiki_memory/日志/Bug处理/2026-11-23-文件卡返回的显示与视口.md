# 文件卡返回的显示与视口

基线为干净的 main/fbbc8db，0.3.3。用户录屏三次 HTML 往返的可见阶段为仅标题、原始 Markdown、恢复正文排版和卡片。旧桌面检查在卡片出现后取样，回归范围缺少返回首屏。保留 HTML Reader 1.0.20 的同窗格卸载对照中，原生编辑器仍会短暂绘出原始标记。0.3.3 的长任务主要耗在悬停模式返回时的整批连线计算。

Agent 决定沿用原生后退和每窗格八次内存快照。快照用实例标记并核对视图、路径和当前操作，用户输入取消延迟恢复。实时预览等点击处和原正文锚点处的排版就绪后修正视口，修正后的下一次合适绘制恢复卡位。阅读模式在段落尚未挂载时保留原生初始化机会。匹配时复用编辑器解析，仅有待迁移键时计算旧换行别名。悬停曲线只为实际交互对象验证路径。

最终 0.3.4 在 Obsidian 1.15.1 的三次同窗格卡片返回中，目标格式化首样从 433–469 ms 降至 144–184 ms，首轮正确卡集与目标出现时最大位置误差 0.25 CSS px，统计窗口内长任务从 10 降至 0。宿主原生的短暂格式化阶段仍可见。两版 Windows 的停稳用例、源文哈希、性能原始记录和本地制品校验见 [验证记录](../../../VALIDATION.md)。
