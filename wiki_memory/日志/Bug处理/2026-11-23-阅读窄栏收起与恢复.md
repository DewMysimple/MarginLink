# 阅读窄栏收起与恢复

从干净的 `main/40d9ed6` 复验。UE6 笔记隔离副本在阅读模式跨过图标宽度阈值时，旧包在跟踪中一次移除或重建 57 张卡片和 71 个引用的逻辑 SVG 节点。初版优化后仍有一次 58 ms 长任务落在收起卡片时。

Agent 选择在两侧同时不足时一次摘除卡片容器，并在同一手势内限量复用有效节点，保留旧菜单的绑定失效规则。无容纳空间时推迟正文测量，无悬停或固定时推迟障碍扫描。阅读分栏共享活跃源码的不可变解析，链接和区段按当前 DOM 归属复核。布局减少重复分配，和旧版对比超过一万个卡片矩形，结果一致。

最终 0.3.3 在 Obsidian 1.15.1 两类侧栏共七轮启用拖动，观察到零浏览器长任务及零布局保存。设置侧栏的最慢一次渲染由 30.0 ms 降到 7.1 ms，完整帧间隔仍高于关闭显示的对照。逐帧几何、两版宿主及回归边界见 [验证记录](../../../VALIDATION.md)。

本轮采用补丁版本号 0.3.3 方便区分此前同名安装包，安装目录和唯一 ZIP 已逐字节核对。正式笔记及隔离副本哈希一致。
