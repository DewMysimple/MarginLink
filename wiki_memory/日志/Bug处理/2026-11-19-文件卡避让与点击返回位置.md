# 文件卡避让与点击返回位置

用户要求将聚合分支合入 main，并修复截图中的卡片重叠、查看文件返回后布局及视口改变。1.10.6 的隔离笔记在基线 `efa1c91` 复现阅读位置从 2400 px 回到 0 px，并在多个布局中发现重复占位。原生历史中的行位置可能陈旧，源视图重建后也会丢失组卡代表与已测卡位。

Agent 选择按原生标签和历史项保存有界、纯内存的布局和文字锚点。兼容普通后退、从目标直接重开来源、Ctrl/Cmd 新标签和折叠状态。来源内容或布局几何变化时重新测量。相邻卡片保留 10 px，虚拟占位区的微调在原邻居之间留出间距。加载大图使正文跨过整行旧卡位时，按实际文字位置重新找最近空位。旧相对坐标继续保存在原布局偏好中。

空位搜索改为扫描不允许的纵向区间。阅读模式按全文建立一次分段索引。性能样本、安装包及桌面复测范围见[验证记录](../../../VALIDATION.md)。接续核对 main、功能分支及 origin 的实际提交，测试只在项目隔离库复跑。

2026-11-19 在 Windows Obsidian 1.10.6、1.15.1 的最终包上共通过 68 次返回和 48 组滚动场景，两版的聚合与设置回归均通过。另通过 555 项单元测试、lint、类型检查、构建和安装包校验。安装包 manifest 版本沿用 0.3.2。
