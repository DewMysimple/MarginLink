# ADR-001 原生双链作为唯一关联数据源

2026-11-10：由 [ADR-002](ADR-002-v0.2可清除的相对布局偏好.md) 替代。原生双链唯一关系源继续有效；原先“不保存单卡位置”的限制被用户 v0.2 明确授权的纯 UI 坐标方案替代。以下保留 v0.1 决策背景。

## 背景与选择

用户在项目开发提示词中明确要求：MarginLink 只做 Obsidian 原生 Wikilink 的可视化交互层。此决策由用户指定，已在 v0.1.0 实现；本页于 2026-11-10 从需求与现有实现回填，不虚构额外历史审批。

新增关系始终以一次公开 Editor 事务写为 `[[目标路径|原文字]]`；优先使用完整路径并交给原生解析器核实精确目标。已有关系、重复 occurrence、锚点和卡片都从原文即时派生，仅存在内存中。官方插件数据只保存四项显示偏好。

## 理由与代价

笔记关闭插件后仍能保有全部链接，避免第二套关系数据漂移。代价是不能保存单条卡片的永久坐标、ID 或拖放位置；空间紧张可隐藏卡片。取舍在 README 明示。

Agent 在此约束内采用严格选区验证、确定性布局及公开 API 的特殊类型能力检查。未知类型缺少已打开的兼容 FileView 时，保留链接并提示，避免外部执行或建立替身笔记；此保守实现有公开 API 无法枚举未打开处理器的限制。

## 实施与验证线索

`src/editor/selection-action.ts` 包含唯一关联写入事务；`src/types.ts` 的白名单限制持久化，`src/main.ts` 经该白名单保存偏好。解析和能力实现见 sources。历史单测和实际客户端验收在 `VALIDATION.md`；本轮仅核实代码及记录，没有再次执行业务测试。未来修改不能用新的存储机制绕过该约束；用户若改变需求，另建替代决策并保留本页历史。
