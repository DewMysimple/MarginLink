# ADR-002 v0.2 可清除的相对布局偏好

## 背景与授权

用户 v0.2 任务书明确允许在原有插件 data.json 保存纯 UI 位置，仍禁止第二套关系、写回 ID 或附加运行时文件。此授权替代 v0.1 不保存单卡坐标的限制；原生双链唯一事实源继续有效。v0.2.0 已实现以下方案，2026-11-10 按源码和隔离验收核实。

## 已采用的选择

- schema 2 分开全局白名单 preferences 与受限 layouts 数组。旧四项偏好不丢失，默认 auto；layout 仍指左右优先，placementMode 表示 auto/free/snap。决定者：用户指定兼容要求，Agent 采用具体结构。
- UI 记录仅含源笔记路径、64 位十六进制弱身份、side、水平带内比例、相对锚点的行高偏移及时间。身份组合散列原生链接原文、前后各 48 字符、同原文出现数量；整篇不唯一则拒绝。没有明文正文副本、绝对窗口像素或关系图。
- 必须先从当前文档获得真实唯一锚点才能恢复位置；删除/局部修改/同原文数量变化使旧记录失效。远处插入通常可保持。非密码学散列只是匹配提示，不宣称绝对唯一。
- Agent 选择保守的重命名/删除策略：任意 Vault rename/delete 失效全部位置，不猜测原生自动改链后的映射；代价是无关位置也可能重置。限额 500 总条数、每笔记 100、90 天过期，drop 后 250ms 合并保存，关闭时刷出待保存项。
- 每视图局部坐标、可见锚点优先、手动位置先占位，其他卡片就近避让；空间不足隐藏，不改保存值。auto 忽略已有手动坐标，切回 free/snap 可恢复。侧栏动画暂隐，几何稳定后显示。
- 公开 API 缺少本项目最低版本一致的设置导航入口；快捷“完整设置”用公开 Modal 共用原生设置表单，原生设置页继续保留。没有调用私有 app.setting 或另外维护偏好副本。

## 验证与代价

90 项单测，1.10.6/1.15.0 各 44 个真实客户端场景；完全退出/重启恢复及 Markdown 哈希检查通过，报告和告警范围见 VALIDATION。data.json 删除只恢复自动位置/默认外观，不能产生或删除链接。

弱身份可能因上下文变化而丢失位置；重命名/删除的全局失效是安全取舍。第三方主题/处理器、popout、其他系统和大规模性能仍需实测。若未来引入更精确的迁移方案，须继续保证原生链接先存在且歧义时不套用位置，并另记替代选择。
