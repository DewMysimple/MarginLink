# MarginLink 中文说明

v0.3.3 可在库外附件与目标目录中的文件重名时确认替换，保留库内路径和原有双链。卡片聚焦后按 **P** 固定、**V** 预览、**Escape** 取消。完整操作和安装步骤见 [README.md](README.md)。

本版安装包为 `dist/margin-link-0.3.3.zip`。在本版源码目录中运行 `npm ci`、`npm run package` 可生成可安装目录 `dist/margin-link/`。升级时保留插件的 `data.json`。本版桌面验收与兼容范围见 [VALIDATION.md](VALIDATION.md)。
