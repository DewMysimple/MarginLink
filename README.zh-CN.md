# MarginLink v0.2 中文说明

完整中文安装、升级、布局数据边界、快捷控制、兼容性及人工验收见 [README.md](README.md)。

v0.2.7 可在原生文件列表识别 HTML 与 XMind。打开 MarginLink 设置的“Obsidian 能识别的文件类型”，可分别设置两个开关，调整后在第三方插件页重载。文件列表中右键“在默认应用中打开”可交给浏览器或 XMind。页边可关联已有文件或创建 Markdown，普通创建留在原文，Ctrl 点击在独立窗口打开新笔记。

可安装目录 `dist/margin-link/`，ZIP `dist/margin-link-0.2.7.zip`。Windows 可双击 [buildStart.cmd](buildStart.cmd) 拉取最新代码并自动生成版本 ZIP；手动生成入口为 `npm run package`（ZIP 命令见完整 README）。真实测试结果见 [VALIDATION.md](VALIDATION.md)，变化记录见 [CHANGELOG.md](CHANGELOG.md)。
