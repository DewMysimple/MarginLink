# MarginLink v0.2 中文说明

完整中文安装、升级、布局数据边界、快捷控制、兼容性及人工验收见 [README.md](README.md)。

v0.2.1 支持左侧图标直达右侧完整设置，直接拖动整张卡片，并保护切页和局部渲染期间的手动位置。原生设置页和快捷 Modal 保留。原生 Wikilink 仍是唯一关联来源，删除 UI 数据只会丢失个性化显示与布局。

可安装目录 `dist/margin-link/`，ZIP `dist/margin-link-0.2.1.zip`，生成入口 `npm run package`（ZIP 命令见完整 README）。真实测试结果见 [VALIDATION.md](VALIDATION.md)，变化记录见 [CHANGELOG.md](CHANGELOG.md)。
