# MarginLink 中文说明

v0.3.0 支持按一次具体双链固定高亮、预览目标笔记，以及按文件夹或文件类型折叠卡片。卡片聚焦后按 **P** 固定、**V** 预览、**Escape** 取消。完整操作和安装步骤见 [README.md](README.md)。

Windows 双击 [buildStart.cmd](buildStart.cmd) 可生成 `dist/margin-link-0.3.0.zip`；`npm run package` 生成可安装目录 `dist/margin-link/`。升级时保留插件的 `data.json`。本版桌面验收与兼容范围见 [VALIDATION.md](VALIDATION.md)。
