# MarginLink v0.2 中文说明

完整中文安装、升级、布局数据边界、快捷控制、兼容性及人工验收见 [README.md](README.md)。

本版加入可保存的 free/snap 卡片位置、曲线/直线/折线、横向/正方形/图标卡片，以及共用状态的原生设置页和快捷 Modal。原生 Wikilink 仍是唯一关联来源，删除 UI 数据只会丢失个性化显示与布局。

可安装目录 `dist/margin-link/`，ZIP `dist/margin-link-0.2.0.zip`，生成入口 `npm run package`。真实测试结果见 [VALIDATION.md](VALIDATION.md)，变化记录见 [CHANGELOG.md](CHANGELOG.md)。
